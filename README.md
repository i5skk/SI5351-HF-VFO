# SI5351-HF-VFO
From a very good software by PU2CLR, revisited and adapted to my own

Original link at:  https://github.com/pu2clr/SI5351
There are also schematic there

I use the VFO as a source for an homemade TX. The VFO can be used in double manner: SPLIT, so it is always on the setted frequency, or SPLIT: in this mode when in RX the frequency is splitted 20 kHz down in order to prevent  signal on a possibly RX connected to TX, when in TX the frequency is what is set and showed in the display. 
I set a lot of possible frequency although I use the VFO/TX just up to 14 or sometimes 18 MHz band. Bat there are many bands set and can be also clear by software mods.
